## Что делает система

Сотрудник подразделения подаёт заявку на публикацию материала в базу знаний → координатор назначает редактора → редактор проверяет и публикует материал или отклоняет заявку.

Статусы: `New` (Поступила) → `InProgress` (На проверке) → `Closed` (Опубликовано) / `Cancelled` (Отклонено).

## Запуск клиента

Нужен Node.js 22.18+ (LTS) или 24.12+. Проверка: `node -v` и `npm -v`.

```bash
cd frontend
npm install
npm run dev
```

Открыть адрес Vite, обычно `http://localhost:5173`.

Экраны переключаются кнопками в шапке: **Заявки** (список), **Новая заявка** (создание), **Вход**. Данные пока тестовые, в коде; сервер подключится в ЛР6.
