## 1. Цель

5. Добавлены стили `src/index.css` (базовые) и `src/App.css` (таблица, состояния, формы).

## 7. Ответы к защите

1. **Что делает Vite и чем он отличается от React?** React — библиотека, которая описывает интерфейс компонентами. Vite — сборщик: он запускает сервер разработки, пересобирает страницу при сохранении файла и собирает `dist/` для публикации. Это разные инструменты, они не заменяют друг друга.
2. **Почему React, а не Vue из методички?** Стек клиента согласован с преподавателем 06.10.2026. Серверная часть при этом осталась курсовой — ASP.NET Core; заменён только клиент.
3. **Почему данные сейчас лежат в массиве?** Сервер появляется в ЛР7. До него клиент разрабатывается отдельно, и массив в коде позволяет проверить вёрстку и состояния экрана, не дожидаясь API.
4. **Зачем `dist/` и `node_modules/` в `.gitignore`?** Это результат сборки и скачанные зависимости: они восстанавливаются командой `npm install` и `npm run build`. В репозитории хранится исходный код, а не то, что из него получается.
