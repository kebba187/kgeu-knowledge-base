## 2. Три критерия на одной заявке

Один новый `id` на весь прогон: id = ____ · number = ____

| Критерий | Экран | Network | SQL | Факт |
|---|---|---|---|---|
| создать | строка со статусом «Поступила» | `POST` → 201 | `status = 'New'` | |
| назначить | редактор виден в строке | `PATCH /assignee` → 200 | `assignee_user_id` не NULL | |
| в работу | статус «На проверке» | `PATCH /status` → 200 | `status = 'InProgress'` | |
