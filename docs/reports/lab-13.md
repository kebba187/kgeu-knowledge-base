## 3. Повтор трёх критериев на одном id

id = ____ · number = ____

| Критерий | Дано | Когда | Тогда | Факт |

## 5. План демонстрации на 7 минут

| Время | Что показываю |
|---|---|
| 0:00–0:30 | заказчик — КГЭУ, главный объект — заявка на публикацию материала, сценарий: от подачи до «на проверке» |
| 0:30–2:30 | вход автором, создание заявки через форму, `201` и `id` в Network |
| 2:30–3:30 | тот же `id` в PostgreSQL (`SELECT … WHERE id = …`) |
| 3:30–4:30 | вход координатором, назначение редактора; статус при этом не меняется |
| 4:30–5:30 | вход редактором, перевод в «На проверке»; тот же id |
| 5:30–6:30 | `POST` без входа → `401`; чужая заявка → `403`; рестарт API → запись на месте |
| 6:30–7:00 | один известный предел: нет отдельной страницы заявки (вынесено в ВКР); вопросы |

Демонстрация начинается с работающего стенда: установка Node и листание исходников в неё не входят.
